# Engineering Notes for Coding Agents

- Reassess this file at every development checkpoint.
- Keep this independent synthetic demo distinct from real auction platforms, property registries, and their proprietary systems.
- Never add scraped real property records or personally identifying data without rights, clearance and user authorization.
- Don't add CAPTCHA evasion, robots bypasses, or unrestricted crawler code.
- Preserve provenance, explicit conflict reports and rejected-row reasons.
- Confirm all country assumptions before expanding locale normalization.
- For any major change update README, tests, data contract and production-boundary doc.
- User SQL style: lowercase keywords and leading commas on subsequent select columns.
